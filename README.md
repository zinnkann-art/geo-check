# Geo-Check Amerika

Lern-App für einen Erdkunde-Test (8. Klasse): stumme Karten von Nord- und Südamerika, Hurrikans und Tornados.
Eine einzige HTML-Datei, ohne Login und ohne Tracking. Der Lernstand bleibt im Browser des Geräts.

**Öffnen:** https://zinnkann-art.github.io/geo-check/

Auf dem iPad in Safari öffnen, dann Teilen → „Zum Home-Bildschirm“. Danach startet die App im Vollbild.

Die Seite wird aus einem lokalen Projekt erzeugt (`node build.mjs`). Änderungen bitte dort vornehmen, nicht hier.
